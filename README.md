# SPIM Suite — Enterprise ERP Platform

Multi-module ERP platform covering finance, HR, payroll, attendance, 
invoicing, projects, and inventory management. Designed, built, and 
deployed end-to-end for real business clients.

**Live product website:** [spectroim.com](https://spectroim.com)

---

## What it does

SPIM Suite is a full business operations platform that replaces 
spreadsheets and disconnected tools with one integrated system. 
Business owners and their teams use it daily to run their 
day-to-day operations.

### Core modules

| Module | Description |
|---|---|
| Dashboard | Real-time business overview and key metrics |
| Finance | Income, expenses, transactions, provisions |
| Reports | Configurable business reports and exports |
| Projects | Project tracking with client and site hierarchy |
| Clients | Client management and relationship tracking |
| Invoicing | Client billing, invoice generation, payment tracking |
| Employee Master | Employee records, roles, and access management |
| Salary Management | Payroll processing and payslip generation |
| Attendance Registry | Attendance tracking with mobile sync via SPIM-Lite |
| Stock Management | Inventory tracking and purchase record management |

## Tech stack

| Layer | Technology |
|---|---|
| Backend | Python, Django, Django REST Framework |
| Database | PostgreSQL — schema design, indexing, query optimisation |
| Frontend | JavaScript, HTML, CSS |
| Mobile companion | React Native / Expo (see SPIM-Lite) |
| Server | Linux (Ubuntu) |
| Version control | Git |

---

## Key features

- **Role-based access control** across all modules
- **Multi-user architecture** supporting teams of any size
- **Real-time mobile sync** — attendance marked on SPIM-Lite 
  appears instantly in the web dashboard
- **REST API** for SPIM-Lite integration and third-party access
- **Business workflow automation** for payroll, attendance, 
  and reporting
- **Multi-branch support** for businesses with multiple locations
