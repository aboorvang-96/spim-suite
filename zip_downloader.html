Project Setup Files

Download the ZIP and place both Python scripts inside E:\Freelancing\Expense_Manager\ then run them in order.

PY
setup_financehub_backend.py
Run first — writes all Django apps & config
PY
setup_financehub_templates.py
Run second — writes all HTML templates
